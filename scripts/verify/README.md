# فحوصات مستقلة للمنطق المحاسبي

سكربتات PHP خام بتشتغل بـ SQLite في الذاكرة، **من غير Laravel ولا composer install**.
مفيدة للتحقق السريع من سلامة تصميم القيود قبل ما تجهّز البيئة كاملة.

```bash
php scripts/verify/accounting-cycle.php    # دورة البيع والشراء والتحصيل + أعمار الديون
php scripts/verify/year-end-closing.php    # قيد الإقفال السنوي + حدود الفترات المقفلة
```

كل سكربت بيرجع exit code = 0 لو كل الفحوصات نجحت، فينفع تحطهم في CI.

> دول مكمّلون لاختبارات PHPUnit في `apps/backend/tests/` مش بديل عنها — الاختبارات
> الحقيقية بتشغّل الكود الفعلي، ودي بتتحقق من صحة التصميم المحاسبي نفسه.
